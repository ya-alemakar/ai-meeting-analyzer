# AI-анализатор видеовстреч

[Открыть приложение на Vercel](https://video-meeting-analyzer.vercel.app)

Ветка `main` содержит актуальную расширенную версию. Исходная Lite-версия доступна в ветке `lite` и по метке `v1.0-lite`. Облачный импорт и последующие доработки находятся в ветке `feature/cloud-import` и по метке `v2.0-cloud`. [Сравнить версии](https://github.com/ya-alemakar/ai-meeting-analyzer/compare/v1.0-lite...v2.0-cloud).

Lite-снимок включает восемь исходных файлов раннего деплоя Vercel с проверенными SHA-1, локальный сервер и инструкцию запуска. История Git начинается с публикации этих снимков.

Локальное учебное приложение принимает MP4 и WebM длительностью до 10 минут и размером до 200 МБ. Сервер извлекает аудио через FFmpeg, распознаёт речь через OpenAI и готовит полный перевод расшифровки и конспект на русском. Для каждого пункта конспекта можно открыть подтверждающий фрагмент исходной расшифровки. Сервер проверяет, что фрагмент встречается в ней дословно.

## Локальный запуск

1. Установите Node.js 22.13+ и FFmpeg. Проверьте, что команды `node --version`, `ffmpeg -version` и `ffprobe -version` доступны.
2. В PowerShell из папки проекта выполните `Copy-Item .env.example .env`. Впишите действующий ключ OpenAI API в `OPENAI_API_KEY` внутри `.env`. Ключ также можно передать серверу как переменную окружения.
3. Выполните `npm ci`, затем `npm start` и откройте [127.0.0.1:3000](http://127.0.0.1:3000).
4. Выберите видео или перетащите его в область загрузки. Откройте запись в истории, чтобы посмотреть конспект, расшифровку и исходные цитаты.

Для обработки нужен интернет. В OpenAI отправляются извлечённая звуковая дорожка и её расшифровка. API-ключ читает только сервер. История, ошибки, расшифровки и конспекты сохраняются в `data/meetings.sqlite`. Сервер удаляет временные видео и аудио после обработки. Запустите один экземпляр сервера на эту базу. Если остановить сервер во время обработки, после перезапуска встреча получит статус «Ошибка», а сохранённая часть результата останется доступной.

## Подключение файла из облака

Скачайте объект из облачного хранилища во временный локальный файл и вызовите общую функцию. Она проверит медиафайл и вернёт длительность, оригинальную расшифровку, перевод и четыре раздела конспекта.

```js
import { processVideo } from './process-video.mjs';

const result = await processVideo(downloadedFilePath);
```

Файл, которым владеет вызывающий код, удаляйте в его блоке `finally`. Для промежуточного сохранения оригинальной расшифровки передайте `{ onTranscript }` вторым аргументом.

Распознавание использует [OpenAI File Transcription](https://developers.openai.com/api/docs/guides/speech-to-text), конспект и перевод используют [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs). Имена моделей можно переопределить в `.env`.

## Версия для Vercel

В облачной версии можно загружать MP4 и WebM до 10 минут, до 10 МБ (10 000 000 байт). Браузер передаёт файлы больше 4 МБ частями через приватное хранилище, чтобы уложиться в [лимит запроса Vercel Functions](https://vercel.com/docs/functions/limitations#request-body-size). Части удаляются после завершения обработки. При закрытии страницы во время загрузки незавершённые части могут остаться в хранилище.

1. Создайте проект из этой папки с конфигурацией `vercel.json`. Используйте Node.js 22 или 24 и включите Fluid Compute для функции обработки.
2. Создайте **Private Blob** и подключите его к среде деплоя. Проверьте наличие серверной переменной `BLOB_READ_WRITE_TOKEN` или настройте доступ через OIDC с `BLOB_STORE_ID`.
3. Добавьте в переменные выбранной среды `OPENAI_API_KEY` и `MEETING_APP_PASSWORD`. Задайте отдельный длинный пароль. Ключ и пароль вводятся через настройки Vercel.
4. Сделайте деплой. На сайте нажмите «Войти в приложение» и введите имя пользователя `meeting` и заданный пароль.

Облачная история общая для пользователей, которым вы дали этот пароль. Приватное хранилище содержит только данные встреч и результаты. Для облачного и локального запуска используется один обработчик видео. Локальная история хранится в своей базе SQLite.

## Импорт записи по ссылке

В опубликованной версии доступна карточка «Импорт из облака». Вставьте общедоступную ссылку на MP4 или WebM из Яндекс.Диска, Dropbox либо публичного Vercel Blob и нажмите «Импортировать запись». Используйте ссылку на отдельный файл из меню «Поделиться». Файл должен укладываться в ограничения — 10 МБ и до 10 минут. Сервер получает адрес скачивания Яндекс.Диска через публичный API без OAuth. Для Dropbox автоматически включается скачивание параметром `dl=1`.

Во время скачивания показан статус, затем запись появляется в истории со статусом «Обрабатывается». После распознавания и анализа откройте её для просмотра русского конспекта и расшифровки. Если файл недоступен, проверьте срок действия ссылки и разрешение на скачивание либо используйте кнопку «Выбрать видео».

Для защиты от повторного AI-анализа сервер вычисляет SHA-256 скачанного содержимого. Повторная ссылка на те же байты открывает существующую встречу, даже если ссылка или имя файла изменились. Атомарная запись в приватный Blob предотвращает параллельную обработку одинаковых импортов. Ошибочную или прерванную обработку можно повторить. Для старых встреч Lite, созданных обычной загрузкой, сохраняется прежнее поведение.

Сервер принимает только HTTPS-адреса поддерживаемых хранилищ, проверяет каждый переход, ограничивает скачивание 45 секундами и размером 10 МБ. Реальный контейнер, звуковая дорожка и длительность проверяются общей функцией `processVideo`. Ссылки с параметрами доступа не записываются в историю.

## Проверки

Проверка синтаксиса выполняется командой `npm run check`. Для запуска тестов используйте Node.js 24.

```powershell
node --test --test-isolation=none tests/cloud-import.test.mjs
node --experimental-test-module-mocks --test --test-isolation=none tests/cloud-routes.test.mjs
```

Тесты проверяют публичный API Яндекс.Диска, его серверы скачивания, ограничения размера, защиту от небезопасных адресов, загрузку файла на 10 МБ по частям и исключение параллельного AI-анализа одинаковых импортов. В автоматических тестах используются изолированные ответы сервисов. Полный импорт реальной записи с Яндекс.Диска, сохранение результата и повторный импорт также проверены в опубликованном приложении.
