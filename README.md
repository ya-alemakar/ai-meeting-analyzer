# AI-анализатор видеовстреч — Lite

Учебное приложение загружает MP4 и WebM длительностью от 2 до 5 минут, извлекает аудио, распознаёт речь и формирует конспект на русском. Доступны краткое содержание, решения, задачи и открытые вопросы. Встречи со статусами «Обрабатывается», «Готово» и «Ошибка» сохраняются в истории. Для пунктов конспекта доступны цитаты из исходной расшифровки.

## Локальный запуск

1. Установите Node.js 22.13+ и FFmpeg. Команды `ffmpeg` и `ffprobe` должны быть доступны в PATH.
2. Выполните `npm ci`.
3. Скопируйте `.env.example` в `.env` и задайте `OPENAI_API_KEY`.
4. Выполните `npm start` и откройте [127.0.0.1:3000](http://127.0.0.1:3000).

При локальном запуске результаты находятся в `data/meetings.sqlite`. Максимальный размер локальной загрузки составляет 200 МБ.

## Публикация на Vercel

Создайте проект из этого репозитория с Node.js 22 или 24. Конфигурация находится в `vercel.json`. Подключите приватное хранилище Vercel Blob и задайте серверные переменные `OPENAI_API_KEY`, `BLOB_READ_WRITE_TOKEN` и `MEETING_APP_PASSWORD`. Для входа используйте логин `meeting` и установленный вами пароль.

В Lite-версии на Vercel принимаются видео до 4 МБ. Результаты сохраняются в приватном Vercel Blob. История общая для пользователей с паролем приложения. Аудио и расшифровка отправляются в OpenAI для обработки. Временные видео и аудио удаляются после обработки.

## Обработка видео

Общая серверная функция `processVideo(filePath, options)` находится в `process-video.mjs`. Она возвращает оригинальную расшифровку, русский перевод, длительность и конспект. Серверные маршруты управляют загрузкой и сохранением результатов.

## Проверка кода

Выполните `npm run check`.

## Версии проекта

Эта базовая версия отмечена меткой `v1.0-lite` и доступна в ветке `lite`. Расширенная версия с облачным импортом доступна в ветках `feature/cloud-import` и `main`, с меткой `v2.0-cloud`.

Восемь файлов облачной Lite-версии получены из раннего опубликованного деплоя Vercel. Для удобного локального запуска добавлен сервер проекта и инструкция.
